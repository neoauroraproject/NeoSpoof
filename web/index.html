آماده

تست ساده

وقتی مسیر عادی برقرار است، فقط آی‌پی سرور مقصد را بزنید. پنل هشت بسته با سورس 192.0.2.1 می‌فرستد تا معلوم شود اسپوف باز است یا نه.

نقش این دستگاه

تست لیست

تا ۱۰۰۰ آی‌پی را بگذارید و آی‌پی سرور مقصد را وارد کنید. پنل مقصد نشان می‌دهد کدام سورس سالم رسیده، کدام عوض شده و کدام نرسیده است.

نقش این دستگاه

تانل آماده

از آی‌پی‌هایی که سالم رسیدند یک جفت کانفیگ کلاینت/سرور ساخته شد و کنار داده‌های پنل ذخیره شد. کلید و پورت‌ها در هر دو طرف یکسان‌اند.

تانل‌ها

برای هر لوکیشن یک تانل بساز؛ هرکدام روی یک پورت SOCKS جدا بالا می‌آید. اگر آی‌پی اسپوف ندهی، آی‌پی‌های بازِ آخرین تست استفاده می‌شوند.

دستور سرور خارج —

این دستور را روی سرور خارج اجرا کنید. کانفیگ را با همان کلید و پورت این تانل ذخیره و سرور را بالا می‌آورد. باینری server باید از قبل آنجا ساخته شده باشد (cargo build --release).
